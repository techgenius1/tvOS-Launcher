# TCL 65" C7K QD-Mini LED Google TV, Brazil (device G08, model "Smart TV Pro", MediaTek mt5896)
# Android 14 (Google TV), firmware UTT2.250416.001, product G08_4K_GB, locale pt-BR.
# Same G08 board and build as examples/tcl-c755-google-tv; that list was the starting point.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-65c7k-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-65c7k-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx. Live TV / HDMI app: com.tcl.tv.
# Keep: tv.mopa.ginga (Ginga, the Brazilian broadcast middleware for TV aberta), com.tcl.tv,
# com.tcl.tvinput, com.tcl.suspension (the Input button's source panel), com.tcl.inputmethod.international
# (the keyboard), com.google.android.tv.remote.service, com.dolby.*, and the other TCL/MediaTek system
# services listed as kept in examples/tcl-c755-google-tv.
# Applied and verified on a real unit on 2026-10-21 (same day, not yet lived with for days): HDMI
# switching, TV aberta (Ginga) and the launcher as Home over Wi-Fi. Chromecast not tested yet.
# setupwraith owned the saved Wi-Fi network: forget and re-join it in Settings first (it then belongs
# to com.android.tv.settings), or disable.sh skips it and Home falls back to its RecoveryActivity.
# dreamx kept on purpose (the owner likes the ambient screensaver).
# Wireless debugging only switches on over Wi-Fi: on Ethernet the toggle flips straight back off.
# Pair once over Wi-Fi, run `adb tcpip 5555`, and port 5555 then answers on either network until reboot.
